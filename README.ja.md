# CROSS — 船舶交差交通の研究シミュレーション

**合成条件下における二つの船舶交通流の交差を研究するプロジェクトです。**

著者: Aleksandr Gulyk（Independent Researcher） · [ORCID](https://orcid.org/0009-0005-8564-4175)

> **現在は非公開・公開準備中です。** PSP と D0 の検証済みソースを取り込み、限定的な CI テストに合格しました。ただし、公開リリースはまだ行っておらず、DOI も発行されていません。

## 研究の対象と制約

CROSS は、自律運航船と有人運航船が混在する二つの交通流の交差を、制御された**合成シナリオ**で検討します。AIS 実測データで校正したモデルではなく、実際の航路容量や航行安全を保証・認証しません。現実の船舶運航・交通管制には使用しないでください。

`psp/` には研究用 PSP のソースとテスト、`simulator/` には固定バージョンの D0 wheel から抽出したソースを収録しています。独立配布予定の PSP Unified は、既定条件の検証済み研究モードと別枠の探索的メータリングモードを区別します。変更した物理条件・船団構成などを自動的に検証済みと扱いません。

## ソースからの簡易実行

Python **3.13** の新しい仮想環境で、リポジトリのルートから実行します。

```sh
python -m pip install -e ./simulator -e ./psp pytest
cross-psp --help
vessel-crossing --help
python tools/verify_source_import.py
```

限定的な GitHub Actions CI では、390 個の固定ソースファイルのハッシュを確認し、30 件のテストが成功しました。ただし、大規模な再現実験や GUI 全機能の検証を行ったことにはなりません。
